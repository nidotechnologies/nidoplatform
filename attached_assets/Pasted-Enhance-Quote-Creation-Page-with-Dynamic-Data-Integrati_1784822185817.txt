Enhance Quote Creation Page with Dynamic Data Integration (Do Not Change UI Design)

The current Quote Creation page UI is correct. Do not modify the layout, styling, spacing, colors, or responsiveness. Only implement the following functional improvements.

1. Quote Number
Quote Number must be auto-generated.

Format:

EST-000001
EST-000002
EST-000003
It should automatically increment based on the last created quotation.
User should not be able to edit this field.
2. Quote Date & Valid Till Date
Quote Date should default to Today's Date.
Valid Till Date should automatically be 7 days after the Quote Date.
If the Quote Date changes, Valid Till Date should automatically recalculate.
User may manually override the Valid Till Date if required.

Example:

Quote Date : 23-07-2026
Valid Till : 30-07-2026
3. Client Name

Rename

Customer Name

to

The dropdown should fetch all active clients from the Clients Master.

Display:

ABC Pvt Ltd

...
4. Auto Populate Client Information

When a Client is selected, automatically fetch the following from the Client Master.

Contact Person

Populate from Client Details.

Billing Address

Populate from Client Billing Address.

Email Recipients

Automatically populate all configured quotation email recipients for that client.

If multiple emails exist, load them all.

Example

sales@abc.com
purchase@abc.com
accounts@abc.com

Users should still be able to add or remove email recipients manually.

Quantity
