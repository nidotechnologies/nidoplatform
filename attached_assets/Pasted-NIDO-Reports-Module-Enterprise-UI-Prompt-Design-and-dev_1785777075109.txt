NIDO Reports Module - Enterprise UI Prompt
Design and develop a complete Enterprise Reports Module for the NIDO Procurement Management Platform.

IMPORTANT:
This is NOT a simple reporting page.

This is the central reporting and business intelligence module for the entire platform.

The design language must match modern ERP systems such as SAP Fiori, Oracle Fusion, Microsoft Dynamics, Zoho Enterprise, Odoo Enterprise and ServiceNow while maintaining the existing NIDO UI style.

The reports must automatically pull data from all existing platform modules.

Use React + TailwindCSS + Shadcn UI.

The design should be premium, clean, professional, spacious, modern, responsive and dashboard-oriented.

Avoid clutter.

Use cards with subtle shadows, rounded corners, professional charts, KPI widgets, filters, expandable sections and export options.

The reports should work with the existing stores already available in the application.
