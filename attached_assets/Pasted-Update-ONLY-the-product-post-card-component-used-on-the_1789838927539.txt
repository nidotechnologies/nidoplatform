# CARD ACTIONS

The Cloud Service Card should have:

### `View Services`

Open the existing product/service detail mechanism if one already exists.

### `Configure`

Open a configuration interface for the selected cloud service.

Do not assume that every cloud service has the same configuration fields.

### `Add to Cart`

Use the existing NIDO cart functionality.

Do not create a separate cart system.
