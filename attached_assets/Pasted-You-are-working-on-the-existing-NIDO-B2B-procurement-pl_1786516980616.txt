==================================================

1. IMPERSONATION BUSINESS RULE
   ==================================================

Only authorized INTERNAL NIDO users can impersonate CLIENT PORTAL USERS.

Client users must NEVER be able to impersonate another user.

Do not allow an internal user to impersonate another internal NIDO user.

The initial allowed role should be:

* Super Admin: ALLOWED
* Admin: ALLOWED
* Manager: configurable/optional
* Procurement Officer: NOT ALLOWED by default
* Other internal users: NOT ALLOWED by default
* Client User: NEVER ALLOWED

Create/use a dedicated permission such as:

client_user_impersonation

Do not hard-code the permission throughout the application.

6. CLIENT TENANT ISOLATION
==========================

This is a CRITICAL SECURITY REQUIREMENT.

When an NIDO admin impersonates a client user:

The admin must see ONLY what that client user is authorized to see.

Example:

Client A user must never see:

* Client B catalogue
* Client B prices
* Client B orders
* Client B users
* Client B reports
* Client B settings
* Client B documents
* Client B stock information
* Any other tenant's data

The impersonated session must pass through the SAME authorization and tenant-isolation logic as a normal client login.

Do NOT bypass client authorization simply because the original user is an admin.
